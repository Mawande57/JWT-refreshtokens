# JWT-refreshtokens
The source code provide a simple way of implementing JWT(JSON web Tokens) and refresh tokens in ASP.NET core 
Confused with how to implement JWT in your REST Api , worry not , the source code from this repo makes it very simple 

From the Program.cs you will find how I use DI for configure and the JWT , which will tell the processor how the program will read the token 

simply clone the repo to test it yourself , if you are still lost or uncomfortable with JWT and refresh tokens have a look at this vid
